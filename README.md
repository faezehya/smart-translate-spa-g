# Smart Translate SPA 🌐🚀

مترجم اسناد مدرن، سریع و ۱۰۰٪ سمت کاربر (Client-Side) با طراحی **آبی شب (Midnight Blue)** و پشتیبانی از مدل‌های هوش مصنوعی محلی **Ollama** و **Google Translate**.

---

## ✨ ویژگی‌های کلیدی

- **۱۰۰٪ آفلاین و محلی (Browser-Based)**: کلیه عملیات پردازش اسناد و تقطیع متون در خود مرورگر انجام شده و هیچ نیازی به سرور بک‌اند ندارد.
- **پشتیبانی از انواع فرمت‌های سند**:
  - اسناد پی‌دی‌اف (PDF)
  - فایل‌های ورد (Word - `.docx`)
  - فایل‌های مارک‌داون (Markdown - `.md`)
  - کتاب‌های الکترونیکی (EPUB - `.epub`)
  - فایل‌های متنی ساده (Plain Text - `.txt`)
- **پایگاه‌داده محلی و دائمی (IndexedDB)**:
  - ذخیره‌سازی خودکار و بلادرنگ قطعات (Chunks) بلافاصله پس از ترجمه.
  - مصونیت کامل در برابر رفرش صفحه، بستن مرورگر یا قطعی ارتباط (Crash Safety).
- **سیستم ادامه ترجمه هوشمند (Persistent Resume)**:
  - عدم ترجمه مجدد بخش‌های تکمیل‌شده.
  - ادامه خودکار از اولین بخش ترجمه‌نشده با امکان توقف و از سرگیری در هر زمان.
- **تب اختصاصی تاریخچه ترجمه‌ها (Translation History)**:
  - مشاهده پیشرفت، تعداد قطعات ترجمه‌شده، وضعیت و مدل استفاده‌شده به همراه زمان آخرین تغییر.
  - امکان ادامه، باز کردن یا حذف اسناد از تاریخچه.
- **ویرایش زنده با ذخیره خودکار**:
  - ویرایش مستقیم متن فارسی با قابلیت Debounce خودکار برای جلوگیری از افت کارایی.
- **پشتیبانی از مدل‌های محلی Ollama**:
  - شناسایی خودکار سرویس لوکال و واکشی لیست مدل‌های دانلود شده.
- **اصلاح خودکار نگارش فارسی**:
  - تنظیم هوشمند نیم‌فاصله‌ها و کاراکترهای فارسی با استاندارد فونت ملی **وزیرمتن**.
- **خروجی‌های چندگانه**:
  - دانلود خروجی به صورت Word (`.docx`)، Markdown (`.md`)، متن (`.txt`) یا کپی مستقیم در کلیپ‌بورد.

## 🛠️ راه‌اندازی و استفاده

تنها کافی است فایل `index.html` را در هر مرورگر مدرنی (Chrome, Edge, Firefox, Safari) باز کنید!

### اتصال به مدل‌های محلی Ollama:
در صورت تمایل به استفاده از هوش مصنوعی کاملاً آفلاین:
1. نرم‌افزار [Ollama](https://ollama.com) را نصب و اجرا کنید.
2. برای حل محدودیت‌های دسترسی مرورگر (CORS)، دستور زیر را در PowerShell اجرا کرده و Ollama را مجدداً راه‌اندازی فرمایید:
   ```powershell
   [System.Environment]::SetEnvironmentVariable('OLLAMA_ORIGINS', '*', 'User')
   ```
3. مدل دلخواه خود (مثلاً `llama3`, `qwen2.5`, `mistral`) را دانلود کنید:
   ```bash
   ollama run llama3:8b
   ```
4. برنامه به طور خودکار به Ollama متصل شده و مدل‌های موجود را در اختیارتان قرار می‌دهد.
